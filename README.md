# MiniFreeRTOS

面向 STM32F407 / Cortex-M4 的小型 RTOS 学习工程，包含内核源码、寄存器版基础工程、16 个 HAL 循序渐进示例和一个综合演示工程。

当前内核实现了静态任务创建、优先级调度、同优先级轮转、任务延时、计数信号量、递归互斥量和带阻塞等待的消息队列。项目名称沿用本地工程命名；本仓库是自定义教学内核，不能按官方 FreeRTOS 的 API 和行为直接替换使用。

## 目录

| 路径 | 内容 |
| --- | --- |
| `Project/RTOS/` | 寄存器版内核 `rtos.c` / `rtos.h` |
| `Project/`、`project.uvprojx` | 原始寄存器版 Keil 工程与驱动 |
| `实例工程/01_单灯心跳/` 至 `实例工程/16_TFT显示RAIN/` | 16 个 HAL 示例，各自包含源码和依赖 |
| `HAL标准历程_MiniFreeRTOS/综合项目_MiniFreeRTOS多任务演示站/` | TFT、触摸、串口、RTC、队列、信号量和互斥量综合演示 |
| `docs/` | 项目计划、内核审查结果和本次整理说明 |

为保留原有相对路径，每个 HAL 示例保留自己的 `Drivers/` 和 `Middlewares/`。这些依赖有重复内容，后续可以在验证各工程后统一提取。

## 打开与构建

目标硬件为正点原子探索者 STM32F407 开发板，外设及跳线要求以各示例的 `说明.txt` 为准。

1. 安装 Keil MDK、相应 Arm 编译器和 STM32F4xx Device Family Pack。
2. 优先从 `实例工程/02_双灯不同周期/Projects/MDK-ARM/atk_f407.uvprojx` 开始。
3. 其他 HAL 示例打开各自 `Projects/MDK-ARM/atk_f407.uvprojx`；综合演示也采用相同目录结构。
4. 各工程保留原编译器设置。HAL 示例多使用 Arm Compiler 5，根目录工程使用 Arm Compiler 6；请按项目目标配置准备工具链。
5. 源码包含中文，请按文件实际编码打开；综合演示及部分 HAL 文件使用 UTF-8。

根目录 `project.uvprojx` 的 `Project/User/main.c` 当前是 OLED 裸机显示测试，没有创建任务或启动调度器。体验多任务请使用上述 HAL 示例。

## 当前状态

本次导入用于保存和整理现有源码，未修复内核逻辑，也未重新编译或上板验证。内核存在启动保护、临界区、上下文切换和同步等待方面的已知问题，详见 [内核审查与改进计划](docs/KERNEL_REVIEW.md)。尤其不能以“已有编译输出”代替运行验证。

建议先完成启动和上下文切换修复，再进行多任务压力测试、超时测试和中断交互测试。
